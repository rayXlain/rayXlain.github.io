# FitHealth39 // ULTRA

ЛФК, но это рейв. Комплексы упражнений для II и III группы здоровья на каждый месяц.

Сайт: https://rayxlain.github.io

## Что внутри

- **Загрузка в стиле BIOS** и выбор «со звуком / тихо».
- **Биометрический шлюз**: вход и регистрация через Firebase Auth, сброс пароля.
- **WebGL-фон**: плазма, синтвейв-солнце и неоновая сетка, реагируют на мышь и бит.
- **Процедурное техно** на WebAudio (128 BPM, без аудиофайлов). Сердце, фон и пластинка качаются в такт.
- **Пластинка месяцев**: крути мышкой, пальцем, колесом или стрелками. Текущий месяц подсвечен, остальные — превью.
- **II группа**: новый комплекс каждый месяц. **III группа**: комплексы под опорно-двигательный аппарат, сердце, зрение и дыхание.
- **Поиск по Ctrl+K** (или `/`) с нечётким поиском: «спина», «глаза», «давление», «март», «бит».
- **Режим тренировки**: таймер 5–20 минут, отсчёт голосом, мотивационные вбросы, конфетти в финале.
- **XP и уровни** от «Диванного кадета» до «Бога ЛФК», серия дней 🔥. Хранится в браузере.
- **Пасхалки**: код Konami, «39», двойной клик по заголовку, 10 кликов по сердцу…

Уважает `prefers-reduced-motion`, работает на телефоне.

## Структура

```
index.html       разметка всех экранов
style.css        стили
js/main.js       сборка всего вместе
js/data.js       каталог комплексов и расписание по месяцам
js/firebase.js   авторизация
js/audio.js      синтезатор и звуковые эффекты
js/shader.js     WebGL-фон
js/fx.js         частицы, конфетти, курсор, тряска
js/vinyl.js      пластинка месяцев
js/palette.js    поиск Ctrl+K
js/workout.js    режим тренировки
js/lightbox.js   просмотр картинки с зумом
js/xp.js         опыт и уровни
sep/             картинки комплексов
```

Сборка не нужна — это статический сайт на ES-модулях. Локально: `npx http-server .` и открыть `http://localhost:8080`.

Комплексы — справочная информация. При хронических заболеваниях нагрузку стоит согласовать с врачом.
